# RAG and context-engineering tutorials

Each notebook compares several RAG or context-engineering pipeline configs with `run_evals()`. Set up with `rapidfireai init` (the evals setup is the default), run `rapidfireai start`, then open the notebooks from `rapidfireai jupyter`. See the [tutorials page](https://oss-docs.rapidfire.ai/en/latest/tutorials.html) and the [FiQA](https://oss-docs.rapidfire.ai/en/latest/rag_fiqa.html), [SciFact](https://oss-docs.rapidfire.ai/en/latest/rag_scifact.html) and [GSM8K](https://oss-docs.rapidfire.ai/en/latest/rag_gsm8k.html) pages in the docs.

| Notebook | What it shows | Models | Needs |
|---|---|---|---|
| [`rf-tutorial-rag-fiqa.ipynb`](rf-tutorial-rag-fiqa.ipynb) | Financial opinion Q&A on FiQA, all self-hosted, with an in-memory FAISS index: 2 chunk sizes × reranker top-n (2, 5) × 2 generators = 8 configs | all-MiniLM-L6-v2 embeddings, ms-marco-MiniLM-L6-v2 reranker, Qwen2.5-0.5B-Instruct and Qwen2.5-3B-Instruct on vLLM | GPU |
| [`rf-tutorial-rag-fiqa-pgvector.ipynb`](rf-tutorial-rag-fiqa-pgvector.ipynb) | Same use case with a PostgreSQL pgvector store. Runs create mode; read and update mode configs are included, commented out | Same as above | GPU; a running pgvector server (the notebook gives a `docker run` command) |
| [`rf-tutorial-rag-fiqa-pinecone.ipynb`](rf-tutorial-rag-fiqa-pinecone.ipynb) | Same use case with a Pinecone serverless index. Runs create mode; read and update mode configs are included, commented out | Same as above | GPU; Pinecone API key |
| [`rf-tutorial-optuna-rag-fiqa.ipynb`](rf-tutorial-optuna-rag-fiqa.ipynb) | `RFOptuna` searches chunking, embedding model, search type and k, reranker model and top-n; maximizes NDCG@5 | 3 sentence-transformers embedders, 3 cross-encoder rerankers, Qwen2.5-0.5B-Instruct on vLLM | GPU; `pip install optuna` |
| [`rf-colab-rag-fiqa-tutorial.ipynb`](rf-colab-rag-fiqa-tutorial.ipynb) ([open in Colab](https://colab.research.google.com/github/RapidFireAI/rapidfireai/blob/main/tutorial_notebooks/rag-contexteng/rf-colab-rag-fiqa-tutorial.ipynb)) | Beginner-friendly FiQA RAG on Colab with a 1% question sample: 2 chunk sizes × 2 reranker top-n = 4 configs | all-MiniLM-L6-v2, ms-marco-MiniLM-L6-v2, Qwen2.5-0.5B-Instruct | Colab GPU runtime |
| [`rf-tutorial-scifact-full-evaluation.ipynb`](rf-tutorial-scifact-full-evaluation.ipynb) | Scientific claim verification on SciFact (SUPPORT, CONTRADICT or NOINFO) with API models: 2 embedding models × similarity or MMR search × 2 generators = 8 configs | text-embedding-3-small and text-embedding-3-large; gpt-5.4-nano, gemini-2.5-flash-lite; reranker on CPU | No GPU; OpenAI and Google API keys |
| [`rf-tutorial-scifact-generators.ipynb`](rf-tutorial-scifact-generators.ipynb) | Same task with 5 generator providers compared in one grid = 5 configs | gpt-5.4-nano on OpenAI and on Azure OpenAI, gemini-2.5-flash-lite, claude-sonnet-4-6, gpt-oss-120b through a LiteLLM (Triton) gateway | No GPU; OpenAI, Anthropic and Google API keys, plus your own Azure OpenAI deployment and OpenAI-compatible gateway (or drop those configs) |
| [`rf-tutorial-optuna-rag-scifact.ipynb`](rf-tutorial-optuna-rag-scifact.ipynb) | `RFOptuna` searches chunking, embedding model, search type and k, reranker model, top-n, generator and max tokens; maximizes accuracy within a budget of 16 runs | OpenAI embeddings, Gemini generators, rerankers on CPU | No GPU; OpenAI and Google API keys; `pip install optuna` |
| [`rf-tutorial-gsm8k-fewshot.ipynb`](rf-tutorial-gsm8k-fewshot.ipynb) | Context engineering with no document retrieval: for each GSM8K question, picks the 3 or 5 most similar of 10 worked examples as few-shot prompts; 6 configs | all-MiniLM-L6-v2 (on GPU); gemini-2.5-flash-lite, gemini-3-flash-preview | GPU; Google API key |
| [`rf-tutorial-MMDocIR.ipynb`](rf-tutorial-MMDocIR.ipynb) | Multimodal RAG over PDFs: Unstructured parses text, tables and images, an LLM summarizes each element, the summaries go into Pinecone, and the originals are offloaded to local disk, S3 or GCS. 2 generators × 2 search types = 4 configs, on the questions about the 15 smallest PDFs | gpt-5.4-nano (summaries and LLM judge), text-embedding-3-small, gpt-5.4-nano and gpt-5.4-mini (generators) | No GPU; `rapidfireai init --multimodal`; OpenAI and Pinecone API keys; downloads about 1 GB of PDFs |

- The notebooks read their data from [`datasets/`](datasets/) through a relative path, so keep that folder next to them.
- [`trackio/`](trackio/) has the FiQA use case with metrics logged to Trackio.
